      Backup and restore

      Your connectors live in a file on this computer (connectors.db), which is not stored on GitHub. The app also makes a dated copy in the backups folder once a day (the last 14 are kept). For an extra copy you can keep somewhere safe, download a backup file:

      Download a backup file

      To restore, or to copy your connectors to another computer, choose a backup file here. Connectors that aren't in the database yet are added. Ones with the same name are left alone, unless you tick the box.

      What the app will store (for the curious)

      Each row is one row of the grid. One letter per cell: . empty, H housing, S shell, P pin, O socket, K key.
